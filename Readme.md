# BLINKIT-CLONE

A simple static front-end clone of Blinkit built with plain HTML and CSS.

## 🔧 What I used

- `HTML` — project structure and content (`index.html`).
- `CSS` — styling and layout (`style.css`).
- `Responsive CSS / Media queries` — responsive rules separated in `media.css`.

## 📁 Project files

- `index.html` — main page
- `style.css` — primary styles
- `media.css` — responsive / breakpoint styles

## ▶️ How to run

1. Clone the repository or download the files.
2. Open `index.html` in any web browser.

## ✨ Notes

- This is a static frontend-only project (no build step or server required).
- Designed to be mobile-responsive using `media.css`.
